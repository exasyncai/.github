# Support

- **Something broke:** open an issue with the "Something went wrong" template. Include the version and the output with addresses removed.
- **Something is missing:** open an issue with the "Something is missing" template.
- **A question about how it works or whether it fits your setup:** GitHub Discussions on this repository.
- **A security problem:** never a public issue. See [SECURITY.md](SECURITY.md).

There is no commercial support contract for this tool. Exasync builds and runs automations for logistics and mid-market operations; if you want this kind of tooling set up for your company, write to operations@exasync.ai.
